# Snakes & Ladders (Saanp Seedhi)

The classic board game with animated dice, hopping tokens, ladder climbs and
snake slides, sound effects and four board themes. Play against 1 to 3
computer players or pass one phone between 2 to 4 friends. Works offline.

- Boards: Classic, Jungle Rush (more ladders), Viper Pit (more snakes) and a
  new Surprise board every game.
- Rules you can switch: exact roll to finish, six gives another roll (three
  sixes end the turn), roll a 6 to start.
- Games save after every move and continue from the home screen.
- Ads: one banner, and an interstitial only after a game ends (2 minute cooldown).

Sounds and the launcher icon are generated by `tool/gen_sounds.py` and
`tool/gen_icon.py`, so there is no third-party art to license.
`tool/icon_512.png` is the 512 px icon for the Play Store listing.

See the repository README for build and release steps.
