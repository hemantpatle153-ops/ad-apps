# Dice Dhamaal

Two classic board games in one app, picked from the home screen. The folder is
still named `snakes_ladders` because the app grew out of it; the Play Store app
is `in.onlysoftware.dice_dhamaal`.

## Ludo (`lib/ludo/`)

Four-colour Ludo with glossy pieces, a tumbling die, captures, home columns
and a winner's podium.

- **vs Computer**: 1 to 3 bots that chase captures, run for home and dodge
  danger.
- **Pass & Play**: 2 to 4 friends on one phone.
- **Play with Friends**: an online room with a 6-character code to share.
  Everyone in the room is on a group voice call while they play.
- Pick your colour; opponents take the seats around you.
- Rules you can switch: quick game (2 pieces), only a 6 opens a piece, three
  sixes lose the turn.
- Up to 5 unfinished offline games save after every move.
- 5 board themes, shared with nothing else.

### How online rooms work

Rooms live in Firebase: anonymous sign-in, and a room in Realtime Database
holding the seats and the list of moves. Every phone applies the same list of
moves to its own copy of the game, so all phones show the same board; a move
that arrives out of turn is ignored. If a player leaves, the others keep
playing and the computer moves their pieces.

Voice chat is WebRTC straight between the phones (encrypted with DTLS-SRTP);
Firebase only passes the connection details. Public STUN servers are enough on
most networks; a TURN relay is the next thing to add if some players can't
hear each other.

The Firebase settings for the `dice-dhamaal` project are built in
(`FirebaseSetup`), so a plain build has online rooms. Another project can be
used by passing `--dart-define=FIREBASE_API_KEY=...` and the other four
names.

See `docs/firebase_setup.md` in the repository for the one-time setup and the
database rules.

## Snakes & Ladders / Saanp Seedhi (`lib/game/`, `lib/ui/`)

The classic board game with animated dice, hopping tokens, ladder climbs and
snake slides, sound effects and four board themes. Play against 1 to 3
computer players or pass one phone between 2 to 4 friends. Works offline.

- Boards: Classic, Jungle Rush (more ladders), Viper Pit (more snakes) and a
  new Surprise board every game.
- Rules you can switch: exact roll to finish, six gives another roll (three
  sixes end the turn), roll a 6 to start.
- Up to 5 unfinished games save after every move; resume or delete them from
  the home screen.

## Ads

One banner, and an interstitial only after a game ends (2 minute cooldown).
Never during a turn.

Sounds and the launcher icon are generated by `tool/gen_sounds.py`,
`tool/gen_ludo_sounds.py` and `tool/gen_icon.py`, so there is no third-party
art to license. `tool/icon_512.png` is the 512 px icon for the Play Store
listing.

See the repository README for build and release steps.
